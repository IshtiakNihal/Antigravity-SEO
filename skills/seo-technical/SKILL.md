# Technical SEO Audit & Remediation

Performs foundational technical audits ensuring search engine crawlers can efficiently discover and index target URLs.

## Verification Checklist
- [ ] HTTP Status returns 200 OK
- [ ] Self-referencing canonical tag matches served URL exactly
- [ ] Robots meta tag contains `index, follow, max-snippet:-1, max-image-preview:large`
- [ ] Exactly one `<h1>` tag matching product/article title
- [ ] Embedded `#rank-math-toc` anchor jump links for Google sitelinks
- [ ] PageSpeed mobile responsiveness and zero layout shift
