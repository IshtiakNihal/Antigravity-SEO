# Master SEO Orchestrator

This skill coordinates all sub-skills within the Antigravity SEO framework.

## Sub-Skills Matrix

* `seo-ecommerce`: Product catalog hygiene, zero-price detection, unique SKU generation, variation management, and high-converting commercial trust badges.
* `seo-geo`: Generative Engine Optimization for ChatGPT, Perplexity, Gemini, and Copilot. Entity density, HTML tables, anti-AI tone.
* `seo-aeo`: Answer Engine Optimization for Google AI Overviews and Featured Snippets. 10-FAQ formula with upfront direct answers.
* `seo-schema`: Schema.org JSON-LD generation and validation (`Product`, `Offer`, `BreadcrumbList`, `FAQPage`).
* `seo-technical`: Crawlability, robots directives, canonical hygiene, redirect loops, and sitemap health.
* `seo-content`: E-E-A-T analysis, information gain, anti-AI tone purifier.
* `seo-sitemap`: XML sitemap discovery, partition monitoring, and lastmod validation.

## Standard Execution Workflow: The 6-Step Cycle

```text
Inspect ──> Implement ──> Test ──> Audit ──> Fix ──> Finalize
```

1. **Inspect:** Audit current catalog, URLs, and metadata. Surface all ৳0 prices, missing SKUs, duplicate titles, and crawl errors.
2. **Implement:** Apply model-specific titles, clean descriptions, 2-column HTML specification tables, and 10 FAQs.
3. **Test:** Verify live HTTP status (200 OK), self-referencing canonicals, and responsive mobile rendering.
4. **Audit:** Re-scan the catalog against technical SEO, GEO citability, and AEO snippet standards.
5. **Fix:** Eliminate any remaining blockers, invalid SKUs, or broken schema markup.
6. **Finalize:** Ping sitemaps, verify Search Console discovery, and persist editor scores.
